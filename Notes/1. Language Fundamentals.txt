- Identifiers
A name in java program is called identifier which can be used for identification purpose
It can be a method name or variable name or class name or label name

class Test {
    public static void main(String[] args){
        int x = 10;
    }
}
Test, main, String, args, x are Identifiers

Rules for defining Java Identifiers
1.  Only allowed characters are 
    a-z, A-Z, 0-9, $, _ 
    If we are using any other character, we will get CE
    Example -   total_number is correct
                total# is incorrect
2.  Identifiers cannot start with digits
    total123 is correct
    123total is incorrect
3.  Java Identifiers are case sensitive. Ofcourse Java is case sensitive
4.  There is no length limit for java identifiers but it is not recommended to use too lenthy identifiers
5.  We cannot use reserved words as Identifiers
    int if = 20; is incorrect
6.  All predefined Class names and Interface names we can use as Identifiers.
    But it is not a good programming practice

- Reserved Words
In Java, some words are reserved to represent some meaning/functionality.
Such type of words are called reserved words

                                        Reserved Words(53)
                                            /   \
                                           /     \
                                Keywords(50)    Reserved Literals(3)
                                  /  \          |- true
                                 /    \         |- false
                                /      \        |- null
                               /        \
                  Used Keywords(48)   Unused Keywords(2)       
                                      |-  goto
                                      |- const 
            
    Data Types(8)       -   byte, short, int, long, float, double, char, boolean
    Flow Control(11)    -   if, else, switch, case, default, while, do, break, continue, return
    Modifiers(11)       -   public, private, protected, static, final, abstract, synchronized, native, strictfp, transient, volatile
    Exception(6)        -   try, catch, throw, throws, finally, assert
    Class(6)            -   class, interface, extends, implements, package, import
    Object(4)           -   new, instanceof, super, this
    void return type    -   In Java, return type is mandatory
                            If a method wont return anything then we have to declare that method with void return type
    Unused(2)           -   goto    -   Usage of goto created several problems in old languages hence SUN people banned this keyword in Java
                            const   -   use final instead of const 
                            Note -  goto and const are unused keyword and if we are trying to use, we will get CE 
    Reserved Literals(3)-   true, false -   value for boolean data types
                            null        -   default value for Object reference
    enum keyword        -   We can use enum to define a group of named concepts
                            Example - enum Month { JAN, FEB, ...., DEC; }

Conslusion 
1. All 53 reserved words in java contains only lowercase alphabets symbols
2. In java, we have only new keyword and no delete keyword because destruction of useless objects is responsibility of GC

- Data Types
In Java every variable and every expression has some type
Each and every variable is clearly defined
Every assignment should be checked by compiler for type compatibility

1. Because of above reasons, we can conclude java langage is strongly typed programming language
2. Java is not considered as pure OOP language because several OOP features are not satisfied by java like operator overloading and multiple inheritance
Moreover, we are depending on primitive data types which are non objects

                                        Primitive Data Types
                                            /           \
                                           /             \
                                        Numeric         Non-Numeric
                                        /   \           |- char
                                       /     \          |- boolean
                                 Integral    Floating
                                 |- byte    |- float
                                 |- short   |- double
                                 |- int
                                 |- long

Except boolean and char, remaining data types are considered as signed data types because we can represent both positive and negative numbers

1. byte                                          _ _ _ _ _ _ _ _
    Size        -   1 byte = 8 bits             |_|_|_|_|_|_|_|_| First bit is sign bit(MSB)
                                                0 = +ve, 1 = -ve
    MAX_VALUE   -   +127(2^7-1)
    MIN_VALUE   -   -128(-2^7)

    The MSB acts as a sign bit
    0 means +ve number, 1 means -ve number
    +ve numbers will be represented directly in the memory whereas -ve numbers will be represented in 2's compliment form
    Examples    -   byte b = 128;       CE: Possible loss of precision
                                        found: int, required: byte
                    byte b = true;      CE: Incompatile Types
                                        found: boolean, required: byte

    Byte is the best choice if we want to handle data in terms of stream either from a file or network(file supported form/network supported form is byte)

2. short
    Size        -   2 bytes -> 16 bits
    MAX_VALUE   -   32767(2^15-1)
    MIN_VALUE   -   -32768(-2^15)

    This is most rarely used data type in java
    Best suitable for 16-bit processors like 8085 but these processors are completely outdated, hence short is also outdated data type
    Example     -   short s = 32768;    CE: Possible loss of precision
                    short s = 123l;     CE: Possible loss of precision

3. int
    Size        -   4 bytes -> 32 bits
    MAX_VALUE   -   2147483647(2^31-1)
    MIN_VALUE   -   -2147483648(-2^31)

    The most commonly used data type is int
    Examples    -   int x = 2147483648;     CE: Integer number too large
                    int x = 2147483648l;    CE: Possible loss of precision
                    int x = 123l;           CE: Possible loss of precision

4. long
    Size        -   8 bytes -> 64 bits
    MAX_VALUE   -   2^63-1
    MIN_VALUE   -   -2^63

    Sometimes int may not be enough to hold big values, then we should go for long type
    Example     -   The amount of distance travelled by light in 1000 days
                    long l = 126000*60*60*24*1000 miles
    Example     -   The number of characters present in a big file may exceed int range, hence return type of length() is long and not int
                    long f = f.length();

Note -  All the above datatypes(byte, short, int, long) meant for representing integral values
        If we eant to represent floating point values then we should go for floating data types

5. float
    Size        -   4 bytes
    MAX_VALUE   -   3.4028235E38 OR 3.4*10^38
    MIN_VALUE   -   -1.4E-45 OR 1.4*10^-45

    If we want 5 to 6 decimals places of accuracy
    Single precision

6. double
    Size        -   8 bytes
    MAX_VALUE   -   1.7976931348623157E308
    MIN_VALUE   -   4.9E-324

    If we want 14 to 15 decimal places of accuracy
    Double precision

7. boolean
    Size        -   NA(Virtual Machine Dependent)
    Range       -   NA(but allowed values are true/false)

    Example     -   boolean b = True;       CE: cannot find symbol

8. char
    Size        -   2 bytes
    Range       -   0 to 65535

    Old languages like(C/C++) are ASCII code based and the number of different allowed ASCII code characters are less than or equal to 256
    To represent these 256 characters, 8 bits are enough. Hence the size of char in old languages is 1 byte
    Java is unicode based and the number of unicode characters are >256 and <65536
    To represent these many characters 8 bits may not be enough, compulsary we should go for 16 bits
    Hence size of char in java is 2 bytes
    https://symbl.cc/en/unicode-table

- Literals
A constant value that can be assigned to the variable is called a literal

Integral Literals
    For integral data types(byte, short, int, long) we can specify literal values in the following ways
    
    1. Decimal Form(Base 10)
        Allowed digits are 0 to 9
        Example -   int x = 10;

    2. Octal Form(Base 8)
        Allowed values are 0 to 7
        Literal values should be prefixed with 0
        Example -   int x = 010;

    3. Hexadecimal Form(Base 16)
        Allowed values are 0 to 9 and a to f
        For extra digits(a to f) we can use both uppercase and lowercase characters
        This is one of very few areas where java is not case sensitive
        Should be prefixed with 0x or 0X 
        Example -   int x = 0x10;

    4. Binary Literals(Base 2)(1.7V Enhancements)
        For integral data types until 1.6V we can specify literal values in decimal, octal and hexadecimal form
        But from 1.7V we can specify literal values even in binary form
        Allowed values are 0 and 1, Literal values should be prefixed with 0B or 0b
        Example -   int x = 0B1111;

    These are only possible ways to specify literal values for integral data types
    Example     -   int x = 0786;       CE: Integer number too large

Floating Point Literals

String Literals
    Any sequence of characters within " " is treated string literal
    String class is Immutable, but can be used much like a primitive type
    StringBuilder class is mutable
    Example     -   String s = "akash";
                    System.out.print(10+10+"10"+10+10+true);

Usage of '_' symbol in numeric literals(1.7V Enhancements)
    double d = 1_23_456.7_8_9;              -   Compiles to 123456.789
    From 1.7V onwards, we can use '_' symbol b/w digits of numeric literal
    Advantage is readability of code will be improved
    At the time of compilation, '_' symbols will be removed automatically, hence after compilation 123456.789

    double d = 1__23_4_5__6.7_8_9;
    We can use more than one '_' symbol also between the digits

    double d = _1_234_56.7_8_9;
    double d = 1_2_3_4_56_.7_8_9;
    double d = 1_2_3_4_56.7_8_9_;
    We can use underscore symbol only between digits else CE
