(Lec-35) - Parsing Request Bodies
    Stream      -   Request read in chunks, then fully parsed. We can start before full request is read
                    Good for parsing files
    Buffers     -   We use buffer to work on Streams
                    It is like a Bus Stop for Streams, holds multiple chunks
    const body = [];
    req.on("data", (chunk) => {
      console.log(chunk);
      body.push(chunk);
    });
    return req.on("end", () => {
      // Buffer them
      const parsedBody = Buffer.concat(body).toString();
      console.log(parsedBody);
      const message = parsedBody.split("=")[1];
      fs.writeFileSync("message.txt", message);
      res.statusCode = 302;
      res.setHeader("Location", "/");
      return res.end();
    });

(Lec-37) - Blocking and Non-Blocking Code
    JS code is non Blocking
    Use callbacks and events => Order changes

    writeFile vs writeFileSync
    writeFileSync   -   Is a Synchronous writing of file and blocks code
    writeFile       -   Do not blocks. Better to use it. 
                        It consists of a callback function as third argument, which triggers when operation completes
    fs.writeFile("message.txt", message, (err) => {
        res.statusCode = 302;
        // # 5. Redirecting Requests
        res.setHeader("Location", "/");
        return res.end();
    });

(Lec-38) - Node.js - Looking Behind the Scenes
    Single Threaded, Event Loop and Blocking Code
    Performance     -   File tasks takes long time, sent to Worker Pool(responsible of Heavy Lifting on multi threads)
                        Worker Pool triggers callback for file operation when completed, that is sent to Event Loop
                        Event Loop handles Event Callbacks 
                        Event Loop -
                            Checks for Timers(Execute setTimeout, setInterval Callbacks)
                            Other callbacks(Execute IO related callbacks that were deferred)
                            Polls(Retrieve new IO events, execute their callbacks. Or defer them. Or move to Timers if any)
                            Check(Execute setImmediate() callbacks)
                            Close Callbacks(Execute all 'close' event callbacks)
                            process.exit(), if no remaining Event Handlers left(refs === 0)
