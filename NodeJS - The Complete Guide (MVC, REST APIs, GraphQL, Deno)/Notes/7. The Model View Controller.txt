(Lec-98) - What is the MVC
    Separation of Concerns
    Models          -   Represent data in code, Work with data like save, fetch, etc
    Views           -   What the user sees, Decoupled from your application code
    Controllers     -   Connecting your Models with Views, contains the in-between logic
    Routes defines the controllers
    Controllers are split across middleware functions
